How it works

You paste a link (or type a topic). The rest happens on its own, or it can stop after each step so you can edit.

  1. WatchReads the captions and looks at frames, so it gets the drawing style and the jokes.
  2. WriteA new script in its own words, with a fact checklist. It never copies sentences.
  3. DrawOne animated scene per line: maps, stickmen with hats, props, speech bubbles.
  4. VoiceNatural narration, with captions timed to the words.
  5. MixMusic and sound effects under the voice, at YouTube loudness.
  6. Package3 titles, a description with real chapters, tags, a thumbnail and a Short.

On your computer

Windows 11, Linux or macOS. You need Python and ffmpeg (the steps install them).

Download
Windows
winget install --id Gyan.FFmpeg -e
winget install --id Python.Python.3.12 -e

Unzip, then double-click start.bat.

Debian / Ubuntu
sudo apt install ffmpeg python3 python3-venv
./start.sh
